3. App Purpose & Target Audience
----------------------------------
ekaTimer is a lightweight, clean, and highly customizable meditation companion.
It provides meditation practitioners with highly accurate, on-device session
timing and statistical metrics without digital distractions.

Key offerings include: 

• Three unique timer frameworks (Timed, target-focused End At, and open-ended Unlimited). 

• Fully customizable session audio configurations (start bell, interval gongs, and end bell sounds) alongside vibration alerts. 

• Automated high-opacity visual dimming to turn the screen dark during meditation, saving battery life on OLED/LCD displays and keeping environments peaceful. 

• Streak tracking and visual statistics broken down by day, week, month, and year to support consistent habit formation.

• Quick-start home screen and lock screen widgets (static shortcuts) utilizing custom URL deep
links to instantly begin sessions.

Target Audience: Meditators, mindfulness practitioners, monastics, and anyone
looking for a secure, offline tool to facilitate and analyze their daily sitting
practice.

4. Setup & Access Instructions

5. External Services & Tools
-------------------------------
ekaTimer is designed with a privacy-first, on-device architecture. It does not
communicate with third-party servers, remote APIs, user analytics trackers, or
artificial intelligence engines.

The app manages all computations locally: 
• Database storage: Session histories are securely written to an on-device SQLite database (sqflite). 
• Daily notifications: Daily sitting reminders are scheduled locally using standard system alarms. 
• Audio alerts: Notification sound paths (WAV files) are packed directly within the compiled app bundle and played through native system components. 
• Data Portability (CSV): Users can export their statistics or import legacy sessions through local .csv files. The app interacts solely with native iOS framework tools (the standard iOS Share Sheet and the file picker sandbox) to guarantee that user-generated data never leaves the device without explicit intent.
